# audio_radar

Визуальный радар направлений по игровому звуку. Программа слушает то, что
уходит на наушники, оценивает, откуда пришёл звук, и рисует направления
поверх экрана. Сделано для игроков, которым слух не даёт определить сторону
самостоятельно.

## Что программа может и чего не может

Из стереопотока физически извлекаются три признака:

| Признак | Полоса | Что даёт |
|---|---|---|
| Разница времени (ITD) | до ~3 кГц | лево/право, надёжно |
| Разница уровней (ILD) | выше ~1.5 кГц | лево/право, надёжно |
| Спектральные вырезы | 5–10 кГц | фронт/тыл, ненадёжно |

**Фронт и тыл не различаются.** Источник спереди и его зеркало сзади дают
одинаковые ITD и ILD — это конус неопределённости, и обойти его из двух
каналов нельзя. Поэтому радар честно рисует обе возможности: яркую метку
впереди и приглушённую сзади. Разрешение этой неоднозначности по спектральным
вырезам пока не реализовано.

**Два одновременных источника** разделяются, только если они занимают разные
участки спектра — например шаг и выстрел. Два одинаковых по тембру звука из
разных сторон по одному кадру не разделит никакой алгоритм: фаза в каждом бине
становится их смесью.

## Настройки игры

В CS2 обязательно выбрать **Stereo Headphones**. Тогда работает Steam Audio и
его HRTF. Без этого панорамирование становится чисто амплитудным, разница
времени тождественно равна нулю, и половина признаков пропадает — картинка
будет стягиваться к центру.

В Valorant соответственно нужно включить HRTF в настройках звука.

## Отдельно: моно-сведение

Если одно ухо не слышит, в стереогарнитуре теряется целый канал вместе со
всеми событиями в нём. Windows → Параметры → Специальные возможности → Звук →
**«Моно звук»** сводит оба канала в каждое ухо. Направление при этом теряется,
но его и так не было, а даёт его радар. Радар и моно-сведение дополняют друг
друга, а не конкурируют.

## Что видно на экране

* **Кольцо.** Передняя половина сплошная, задняя — пунктиром: сразу видно,
  какая половина является зеркальной догадкой.
* **Красные метки** — источники впереди, до четырёх одновременно. Размер
  передаёт громкость, прозрачность — надёжность оценки.
* **Оранжевые метки** — те же источники в зеркальном положении сзади.
* **Бахрома по кольцу** — полный отклик по азимуту. Широкая размытая бахрома
  означает, что направление определено плохо; узкий всплеск — что уверенно.

Показанная неопределённость полезнее ложной уверенности: «слева, но фронт или
тыл неясно» — это рабочая информация, а одна стрелка, указавшая в пустоту, —
нет.

## Калибровка

Встроенный профиль `cs2-steamaudio-default` задан аналитически: ITD по формуле
Вудворта при радиусе головы 8.75 см, ILD по приближению сферической головы.
Этого достаточно, чтобы играть.

Точнее будет таблица, снятая с самой HRTF. Положите файл `calibration.txt` в
рабочий каталог (или укажите путь в переменной `AUDIO_RADAR_CALIBRATION`):

```
name       cs2-measured
itd_band   200 3000

# азимут в градусах, ITD в микросекундах
# 0 — прямо перед игроком, +90 — справа
itd        -90 -655
itd        -45 -480
itd          0    0
itd         45  480
itd         90  655

# полоса частот в герцах, затем азимут и ILD в децибелах
ild_band   4000 6000
ild        -90 -15.0
ild          0   0.0
ild         90  15.0
```

Узлы, которых нет в файле, доинтерполируются линейно, так что измерять каждый
градус не нужно — хватит шага в 5–10 градусов. Строки после `#` игнорируются.

Чтобы получить такую таблицу для CS2, прогоните импульс через HRTF Steam Audio
на каждом азимуте и снимите задержку и разницу уровней по полосам.

## Сборка и запуск

```
cargo run --release
```

Логи включаются через `RUST_LOG=info`.

Сборка и тесты проверяются на Linux и Windows в GitHub Actions
(`.github/workflows/ci.yml`).

Если сборка падает на `src/audio.rs` в строке с `stream_config.sample_rate.0`,
значит в вашей версии cpal частота дискретизации хранится не новотипом
`SampleRate`, а простым `u32` — тогда уберите `.0`.

## Важное предупреждение про античиты

Захват звука через loopback не читает память игры, но:

* Vanguard в Valorant работает в режиме ядра и недружелюбен к оверлеям поверх
  игры;
* правила Riot и Valve запрещают стороннее ПО, дающее преимущество, и
  инструмент, показывающий позицию по звуку, под эту формулировку подпадает.

Риск блокировки аккаунта реален. Он заметно ниже, если выводить радар **не
оверлеем поверх игры, а отдельным окном на втором мониторе**. Перед
использованием в рейтинговых матчах имеет смысл написать в поддержку и описать
ситуацию.
